# Subsonic Wind Tunnel

A work-in-progress subsonic wind tunnel designed and built by **Mohamed Chabou** and **Muhammad Zakariyya Hossain**. The project is based on and adapted from James P. K. Wadhwani's *Subsonic Wind Tunnel* design on Instructables.

## Overview

The goal of this project is to construct a functional small-scale wind tunnel for experimenting with airflow and aerodynamic behavior. The tunnel is currently approximately **70% complete**, with the main structure and several major components assembled.

This repository documents our design process, construction progress, future electronics integration, and eventual testing of the completed wind tunnel.

## Current Progress

**Status: 🚧 In Progress — ~70% Complete**

Current work includes:

- Construction and assembly of the wind tunnel structure
- Fabrication of the test section and surrounding components
- Integration of airflow components
- Ongoing mechanical improvements and finishing
- Planning for electronic sensing and data collection

Photos of the build process can be found in the `images/` directory.
